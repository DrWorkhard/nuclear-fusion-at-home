## Scope

Qualify a separate saved-data auditor before any new native search. This stage
permits synthetic wiring/failure tests and NumPy/SciPy reconstruction from the
eight historical native seed bundles. Independent cumulative-certificate
reconstruction is permitted. Native model construction, B/A/VJP calls, producer
certificates, equilibrium solves, optimization and new target generation are not.

Keep all historical sources and the qualified cell, controller, graph auditor,
storage and numerical/certificate primitives unchanged. Add a new adapter/auditor
and tests; never change a candidate's verifier to make that candidate pass.
Use fresh outputs and preserve failed checks. This registration does not authorize
the pilot: native-plumbing and physical-auditor qualifications plus a committed
execution checkpoint must precede that separate stage.

## Input and execution evidence

The core reconstruction API takes an explicitly admitted original context,
complete source manifest and an explicitly supplied returned cell reference.
Rebuild the expected context from that source and compare it exactly, including
historical numerical arrays. Require the complete saved-graph audit to pass before
physics traversal. Do not infer completion by searching directories.

The core API cannot authenticate source admission or parent execution merely
from supplied dictionaries. Its report must keep those claims false. A separate
launch/checkpoint layer must bind the actual source admission and the explicitly
returned parent acknowledgement before using a core report as experiment evidence.
Qualification of the reconstruction component must not be called full pilot
admission. Tests reject substituted contexts and results with a failed graph.

## Reconstruction, unchanged thresholds

1. Traverse every certificate manifest, including rejected/uncertified proposals.
   Independently recalculate against the original seed and original geometry
   report using `coil_perturbation_audit.audit_certificate`. A faithfully reported
   negative certificate passes verification; it does not become certified.
2. Traverse every numerical bundle, including rejected current/Armijo trials.
   Read all sixteen raw arrays with the qualified canonical reader and validate
   the complete bundle schema. Historical archives retain their original checked
   reader. Reconstruct the 401-point vacuum target identity, archived interior
   target, fixed B² and signed flux with `audit_clear_coil_field_start.target`.
3. Translate each new bundle into the existing independent `field_row` interface
   at the fixed construction grid. Reconstruct all discrete objective/metric
   values, coil geometry, currents and flux. Reuse tolerances 5e-10 relative /
   1e-12 absolute for metrics, calibrated flux 1e-12 relative, and direct B/A
   5e-10 relative. Check 64 ordered points in each boundary/interior/loop array:
   six vector comparisons per bundle. No new or relaxed tolerance.
4. Feed all ten independently reconstructed startup objective values into
   `protected_startup.derivative_screen`: two protected low-mode directions,
   two step sizes, four recorded plus four reconstructed derivative checks,
   unchanged 2e-4 relative OR 1e-8 absolute limit. Preserve exact seed/history,
   seed/repeat, fresh-search-seed and selected-replay checks from the graph audit.
   Do not reuse the older full-coordinate FD stencil or seed-only row identities.
5. Report every reconstructed bundle/certificate, exact reference identities,
   independent counts, startup outcomes and selected-versus-search-seed changes
   separately for objective, normal RMS/max and inner-vector RMS. These changes
   are diagnostic values, not resolved fine-grid improvements or Pareto dominance.

Fail closed on malformed data, missing/reordered evidence, numerical disagreement
or failed publication. A successful report reference exists only if publication
returns successfully. No retry or partial result may acquire a complete-pass flag.

## Required qualification

- Synthetic complete histories: both classes/methods, accepted and rejected
  trials, null direction, current/Armijo/geometry rejection and exhausted budgets.
  Stub numerical/certificate functions only in explicitly synthetic wiring tests.
- Reject tampered coordinates, seed/report, target/normalization/current, metrics,
  arrays, ordered startup values and missing/substituted manifest identities.
  Ensure negative certificates and rejected numerical trials are still checked.
- Read-only reconstruction of all eight actual saved native seed bundles against
  the admitted source graph, including independent seed certificates and all six
  sampled B/A comparisons. Old full-space probes cannot qualify the new low-mode
  stencil; its real qualification remains a runtime requirement before search.
- Independent internal review, focused/public/docs/full regression and exact
  source/artifact binding. Run resource-heavy checks serially with the existing
  native environment unchanged and a 3 GiB initial / 2 GiB ongoing disk reserve.

## Limits on claims

Name passes narrowly: complete saved-metric reconstruction, sampled direct B/A,
independent cumulative certificates, protected directional startup screen and
saved-graph integrity. These checks do not independently verify every full-grid
field value or every gradient component. Preserve false flags for universal
field/gradient verification, physical admission, fine-grid acceptance, realized
field transfer, Step 4, SoTA and MS1. Native runtime screens, all fine-grid/flux
gates and the physical packages 4A–4D remain necessary.
