## Purpose and launch condition

Connect the already specified diagnostic experiment to its qualified execution
and independent evidence checks. This is not a new optimizer, changed budget,
new acceptance profile or permission to skip remaining qualifications.

Launcher implementation and synthetic wiring tests may proceed. **Native
execution must wait** for completed, committed native-plumbing and saved-physics
qualification records, independent launcher review/tests and a committed execution
checkpoint identifying their exact source/evidence bytes. The native environment
and historical external checkouts remain unchanged. No physical/SoTA/MS1 claim
follows from the launcher qualification or coarse search.

## Exact experiment and source binding

Run the original eight cases in their original order: reference/selected target,
six/eight base coils, N/V objective. Both original ns=401 vacuum targets, the
selected geometry seeds and every historical rejection remain unchanged. Preserve
the original deterministic controller, full named coefficients, low modes,
current elimination, certificate origin, limits and per-cell work caps.

Additive launch sources bind the full admitted native source graph, completed
plumbing and saved-physics qualification records, their source/artifact identities,
this protocol and all new launcher code/tests. Require committed matching source
bytes before work. Do not replace or relax a predecessor's source checks. Bind
the same complete manifest before/after the study and before/after each worker;
no tracked edits, environment changes or concurrent heavy work during execution.

## Execution and independent checks

1. Start a fresh study directory and require 3 GiB free space; retain 2 GiB live.
   Use the qualified parent supervisor serially, with its fixed 1,800-second cell,
   600-second search, one-thread environment, owned process group and control pipe.
   The parent clock includes configuration/source admission and launch work.
2. Worker dependencies explicitly unwrap the admitted context and instantiate
   the qualified native adapter. No hidden default or test adapter may be used
   in native mode. Preserve ten startup bundles, fresh search seed, at most twenty
   field trials / 116 proposals and fresh original-model selected replay. Maximum
   per cell: 128 certificates, 32 bundles, two model initializations, 290 native
   requests. No retries, resumption or transfer of unused budget.
3. The qualified recorded-value startup derivative/history/replay gates precede
   search. The parent validates the returned worker/core references and complete
   saved-graph audit before returning its acknowledgement. Do not discover result
   files as a substitute for any returned reference.
4. After a successful acknowledgement, independently reconstruct the completed
   cell using the separately qualified saved-physics auditor. All certificates,
   all evaluated bundles and the reconstructed protected startup screen must be
   checked, including rejected proposals/trials. This posthoc work has a separately
   recorded elapsed time and is not charged to the construction/native budget.
5. Bind the returned parent acknowledgement and returned independent report into
   a per-case record. Link their case, complete source manifest, configuration and
   exact cell result; preserve both reports' narrower scope flags. The launcher
   may assert only completed construction and independent coarse verification,
   never physical admission, fine-grid acceptance or Step 4 completion.

A failed cell keeps its successful prefixes and an explicit failed record; no
found tail acquires acknowledgement. Never retry that case automatically. Continue
to the next registered case only if the owned child group has been cleaned up,
the complete source identity is unchanged and resources still pass. Common source,
cleanup or storage failures stop the study; remaining cases stay unexecuted.
Keep actual confirmed counts separate from unknown failed tails and upper bounds.

## Synthetic launcher qualification

- Verify exact eight-case order, immutable source/qualification pins and unwrapping
  into the explicit worker dependencies; reject incomplete/wrong qualification,
  changed committed sources or mismatched case/source/result/acknowledgement.
- Substitute only explicitly labelled synthetic workers/auditors in tests; reuse
  the existing complete synthetic pipeline instead of invoking native fields.
- Exercise completed negative searches, per-cell failures, failed independent
  reconstruction, resource/cleanup/source failures and final-publication failure.
  No failed path can acquire complete construction/verification flags.
- Check exact source freeze and narrow report claims; run focused/public/docs/full
  regression and independent internal review before the execution checkpoint.

## Required follow-on phase and interpretation

Report each cell's optimization objective, independently reconstructed normal
RMS/max and inner-vector RMS separately against its own seed. No cross-N/V objective
ranking, resolved fine-grid gain or Pareto claim. Retain negative outcomes.

After construction, the original separate fine phase is still mandatory for all
eight selected states, including seed fallbacks: six field/interior grids, both
full flux blocks, four direct geometry grids and sampled independent B/A, with
selected coarse currents frozen. Its launcher/admission must be qualified before
execution. Fine values cannot influence the completed selection. A partial or
failed construction does not silently waive missing fine checks.

Even a complete successful diagnostic pilot does not close realization/transfer
4A, coupled improvement 4B, pressure/confinement 4C or finite-build robustness 4D.
