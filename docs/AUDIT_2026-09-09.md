# Baseline audit — 2026-09-09

## Decision

The previous claim that only SQuID-C author data remained missing is withdrawn.
The repository provides useful reproduced calculations and an intake scaffold,
but does not yet provide a qualified scientific admission pipeline or a credible
claim of improved stellarator design. No SoTA improvement has been established.

This audit began on August 31 and resumed on September 9. It inspected source,
tests, raw outputs, evidence and paper definitions. Corrections below supersede
the affected historical findings. Old evidence is retained; reevaluations have
new dated filenames. Solver outputs were not modified to obtain a pass.

The initial claim that the real files lacked boundary metadata was too broad:
they lacked the exact variable name queried by our code. Inspection of the
complete variable list found the proper NetCDF logical name. This correction
matters because reading the actual output is stronger than inferring the state
from an input default.

## Scientific claims that remain unqualified

The QI residual's existing resolution study fails to establish a converged
objective. The custom fraction of negative differences of alpha-averaged J is
not a published maximum-J certificate: averaging can hide unfavorable field
lines. Running the published J routine is useful, but does not settle this.
The NEO paper cross-check remains failed; SIMPLE runs are smoke-scale.

Finite-build mesh checks establish tags, nonzero tetrahedron volumes and a
volume estimate. They do not prove absence of self-intersections, acceptable
element quality, section orientation, manifoldness or solid clearance. The last
structural mesh pair passes a 10% change screen; that is not demonstrated mesh
independence. Reported displacement and stress already exceed the physical
validity of the linear model. These results qualify numerical execution paths.

The optimization screening did not produce a strong feasible constrained
baseline or an equal-budget method ranking. W7-X-target optimized benchmark
coils must not be described as an as-built W7-X coil validation. A vacuum
free-boundary holdout does not establish finite-pressure reactor performance.

## Source corrections

The [SQuID-C paper](https://doi.org/10.1017/S0022377825100974), sections 2.2, 3
and 3.5, supports the nominal 2% beta and linear-pressure coil-generated result.
It explicitly identifies the stability scan as free-boundary and uses different
profiles there. Mapping the canonical result to a free-boundary artifact requires
author confirmation. The earlier beta interval [0.0195, 0.0205) had no stated
basis and was removed. Field-error absolute-value reduction, averaging weights,
grid and inferred rounding intervals need confirmation. Coil 3 c/a is printed
0.88; its inferred rounding half-width is 0.005. Printed table strings now retain
precision. Article licensing does not establish separate dataset licensing.

The August 31 availability audit remains a bounded historical search, not proof
of present absence. This turn rechecked the publisher text but did not repeat
the complete repository/registry search. Future searches should also cover
IPP/MPG repositories and author data releases. No author was contacted.

## Verification and limits

Observed results: Ruff passes; local suite 50 passed, including three real-data
integration checks. A fresh detached clone overlaid with the audited working
snapshot passes the exact run_core_ci.sh command: 47 passed, 3 explicitly skipped
because external scientific data are absent. uv installs 11 core/dev packages.
An additional 1,645 malformed manifest mutations produce zero uncaught exceptions;
this is a robustness probe, not proof that every invalid package is rejected.
All 58 path/SHA-256 pairs across evidence, manifests and references match local
files. This count excludes hash-only records without a resolvable path. New
reevaluation outputs include hashes of their evaluator source files.

- Adversarial core tests cover malformed types, nonfinite values, self-lineage,
  path aliases, empty metrics, logical-field aliases, missing/masked metadata,
  wrong beta/iota/version/termination/residuals, CLI failure and detached HEAD.
- Real nfp=1 and nfp=2 Goodman data are reevaluated in the new dated intake JSONs.
- Existing independent VMEC 8.52 and VMEC++ wouts are reevaluated with 63-variable
  comparison and corrected real-space tolerances in the new dated W7-X JSONs.
  Both report ier_flag=0 and force residuals within the requested level.
- The 48-minute native reference solve, particle ensembles, optimization and
  structural solves were not rerun in this audit. Their original scientific
  limitations remain; passing a core test suite does not validate those models.
- File hash agreement checks integrity of available files, not correctness of
  their contents or proof of which executable originally generated them.

## Next work, in order

1. Freeze a mathematical QI/second-invariant assessment, its resolutions and
   tolerances before new experiments; test field-line-wise behavior and transfer.
2. Establish a feasible constrained classical coil baseline with correct budget
   accounting. Only then run method comparisons or claim Pareto improvements.
3. Add solid-geometry validity and a physically meaningful mechanical load/support
   model; qualify errors before including their scores in optimization.
4. Implement scientific admission around a public real-data fixture: reconstruct
   coils, compare field/error quadrature and tie outputs to inputs and profiles.
5. Obtain canonical-state/metric clarification and an authoritative SQuID-C
   package, then freeze a prospective reproduction protocol for that release.

Data acquisition can proceed alongside the internal work, but successful
scientific reproduction remains a gate before optimization claims.
